How I work

The same five steps whether the answer turns out to be a process change, a dashboard or a model.

  1. Understand

    Talk to the people involved and map how work happens today.

  2. Research

    Test the assumptions against data and the market before designing anything.

  3. Specify

    Write requirements and rules precise enough to build and test.

  4. Build and analyse

    Model the data, build the dashboard or model, and check the numbers.

  5. Test and measure

    Prove it works with users, then track whether it moved the metric.
